# 代肝运营台 · 安装与使用说明

一个**单人自用**的代肝管理后台：游戏 → 服务与价格 → 客户 → 登录凭证保险箱 → 订单 → 进度记录 → 财务，外加报价单生成。

所有业务数据和登录凭证**只存在你自己的电脑上**，不上传任何一个服务器。程序跑起来是一个本地服务，界面在窗口里打开。

---

## 下载

| 文件 | 说明 |
| --- | --- |
| `DaiganOps-setup-2.1.1.exe` | **安装版**，约 98 MB。装到当前用户目录，建开始菜单和桌面快捷方式 |

只支持 **Windows 10 / 11（64 位）**。

> 安装包没有做代码签名，首次运行 Windows 会提示「未知发布者」。点「更多信息」→「仍要运行」即可，不影响功能。

> **如果游戏是以管理员身份运行的**（鸣潮的启动器常见），本程序也要用同样的权限打开：
> 右键快捷方式 →「以管理员身份运行」，或者在「属性 → 兼容性」里勾上「以管理员身份运行此程序」。
> 原因是 Windows 的 UIPI 不允许普通权限的程序给管理员窗口发送按键 —— 窗口能切到前台，
> 但 B / M 永远到不了游戏。程序会在按下第一次按键前就把这件事说出来，不会空等。

## 安装

1. 双击 `DaiganOps-setup-2.1.1.exe`。
2. 选择安装位置（默认装到当前用户目录，不需要管理员权限）。
3. 装完会自动创建桌面和开始菜单快捷方式：**代肝运营台**。

**用户机上不需要装 Node.js**，运行时已经在安装包里了。

---

## 第一次打开

首次启动会引导你设三样东西：

1. **店铺招牌名** —— 会出现在导出的价格表和报价单抬头。
2. **登录密码** —— 打开界面时要输。
3. **保险箱密码** —— 单独一套，用来加密登录凭证。

> ⚠️ **保险箱密码忘了就真的解不开，没有后门、没有找回。** 请存进密码管理器。
> 登录密码忘了还能重置，保险箱密码不能（见下面「忘了密码」）。

### 建议的录入顺序

1. **价格表 → 新建价格表** —— 一张价格表 = 一个游戏，顺手把区服填上（逗号分隔）。
2. **在价格表里「新建大类」** —— 日常 / 周常 / 深渊 / 活动 / 材料 / 成就……
3. **在大类里「加服务项」** —— 每日委托、清体力、深渊 12 层……选一种计价方式，填单价。
4. **服务项详情 → 阶梯价 / 套餐与增项** —— 数量大的加阶梯价；加急、指定角色做成增项。
5. **客户** —— 录第一个客户，手机号是客户的标识。
6. **订单 → 开新单** —— 选客户、勾服务，价格自动算出来。

> 结构是 **游戏（一张价格表）→ 大类 → 服务项**。服务项只能挂在大类里，所以先有大类、再有服务项。

### 五种计价方式

| 方式 | 用在什么上 | 例子 |
| --- | --- | --- |
| 固定价 | 一口价的服务 | 周本全清 25 元 |
| 按天 | 包月、日常托管 | 每日委托 5 元/天 × 30 天 |
| 按次 | 一次一次算 | 清体力 3 元/次 |
| 按数量 | 数量越大越便宜 | 深渊 1~5 层 30/层，6~12 层 25/层 |
| 套餐价 | 打包一堆内容 | 活动全包 120 元/套 |

## 你的数据在哪

安装版的数据放在：

```
%APPDATA%\daigan-ops-console\data
```

在文件资源管理器地址栏粘贴 `%APPDATA%\daigan-ops-console` 就能打开。

**把整个 `data` 文件夹拷走就是一份完整备份。**

也可以走 **设置 → 导出一份备份**，会下载一个 JSON 文件（含全部业务数据）。凭证在文件里仍然是**密文**，换台电脑要用同一个保险箱密码才能解开。

> 「下载整包备份」（`.tar.gz`）会额外打包 `data/uploads` 里的图片素材，适合换电脑或整机还原。
> Windows 上解压中文文件名建议用 **7-Zip**，系统自带的 `tar` 会把中文名解成乱码。

### 关于局域网访问

桌面版**默认只监听 `127.0.0.1`**，也就是只有这台电脑能打开，手机连不上。

想用手机访问，需要设环境变量 `XFC_HOST=0.0.0.0` 再启动。这种情况下同一 WiFi 下的设备都能访问，并且要靠登录密码挡住——**别在公共网络下这么开**。

## 卸载

Windows 设置 → 应用 → 找到「代肝运营台」→ 卸载。

**卸载不会删除你的数据**（`%APPDATA%\daigan-ops-console` 会保留），重装后数据还在。要彻底清掉就手动删那个目录。

## 常见问题

**窗口一闪就没了？**
看 `%APPDATA%\daigan-ops-console\data\desktop\desktop.log` 里的日志。

**点关闭窗口，程序还在？**
是的，关窗口 = 收进托盘，后端还在跑。要真正退出用**托盘图标右键 → 退出**。系统关机时会自动退出。

**端口被占用？**
桌面版会自动从 8787 往后找最多 20 个空闲端口，不需要你手动改。

**忘了登录密码？**
需要手动操作，且只对**从源码运行**的场景有效——安装版没有附带这些脚本。安装版用户请直接联系发布者。
源码场景下执行 `node scripts/tools/reset-password.mjs`（清掉密码，回到初始化引导）或 `node scripts/tools/reset-password.mjs 新密码`。它**只动登录密码**，游戏、价格表、客户、订单、凭证一概不碰。

**忘了保险箱密码？**
没有找回办法。备份文件里的凭证是密文，只能靠同一个保险箱密码解开，**换密码就解不开了**。

**手机打不开？**
桌面版默认只绑 `127.0.0.1`，手机连不上是正常现象。要开得设 `XFC_HOST=0.0.0.0`（见上面「关于局域网访问」），并且手机和电脑要在同一个 WiFi、Windows 防火墙要允许访问。

**导出图片没反应 / 下载文件夹里没东西？**
浏览器可能拦掉了「连续下载多个文件」。把导出范围改成「全部游戏合并成一份」就只下一个文件，或者允许这个网站下载多个文件。

**生成 Word 打不开？**
它是标准 `.docx`，Word 和 WPS 都能开。手机如果当成未知文件，先存下来再用 WPS 打开。

## 屏幕识别（记进度时自动读资源数字）

这个功能会用 OCR 识别游戏画面上的数字。**不装额外引擎也能用**，走 Windows 自带的 OCR，但准确率有限——超宽分辨率下可能把 `2174` 读成 `21`。

想认得更准，去 **设置 → 屏幕识别**：

- **一键安装依赖**（Python 视觉后端，约 200MB）—— 实测十一种分辨率全对。需要 **Python 3.10 ~ 3.14**（推荐 3.14，3.15 目前装不上）。它会建一个项目内的 `data\vision-venv`，不动你系统里的 Python。
- 或者装 **RapidOCR-json**（约 70MB，不需要 AVX），结果一样，不需要 Python。

> 这部分**完全可选**。不用记进度自动识别的话，忽略即可。
