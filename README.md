# 代肝价格查询 · 私用运营台

一个**单人自用**的代肝管理后台。不是商城，没有客户注册登录，没有多代肝入驻。
打开就是七个模块：游戏 → 服务与价格 → 客户 → 登录凭证保险箱 → 订单 → 进度记录 → 财务，
外加一个「报价单生成」。

零第三方依赖，只用 Node.js 自带的模块，数据全部存在你这台电脑上。

---

## 一、跑起来

需要 **Node.js 22.5 或更高版本**（用到了内置的 `node:sqlite`）。
没装的话去 <https://nodejs.org> 下载 LTS 版本，一路下一步即可。

| 系统 | 怎么做 |
| --- | --- |
| Windows | 双击 **`start.cmd`** |
| Windows（只给本机用） | 双击 **`start-local.cmd`** |
| macOS / Linux | 终端里 `./start.sh`，或 `./start.sh --local` |

启动后窗口里会打印两个网址：

```
本机打开：   http://127.0.0.1:8787
手机打开：   http://192.168.1.7:8787     （手机要和这台电脑连同一个 WiFi）
```

**保持那个窗口开着**——关掉窗口就等于关掉后台。按 `Ctrl+C` 退出。

端口被占用了就换一个：`start.cmd --port 8888`。

## 二、第一次用，按这个顺序

首次打开会引导你设三样东西：店铺招牌名、登录密码、保险箱密码。

然后建议按顺序录：

1. **价格表 → 新建价格表** —— 一张价格表 = 一个游戏。建的时候顺手把区服填上（逗号分隔），
   想好看还可以传个图标。
2. **在价格表里「新建大类」** —— 日常 / 周常 / 深渊 / 活动 / 材料 / 成就……
3. **在大类里「加服务项」** —— 每日委托、清体力、深渊 12 层……选一种计价方式，填单价。
   **服务项只能挂在大类里**，所以先有大类、再有服务项。
4. **服务项详情 → 阶梯价 / 套餐与增项** —— 数量大的（比如深渊层数）加阶梯价；
   加急、指定角色、不动原石这类做成增项。
5. **客户** —— 录第一个客户，手机号填上（它是客户的标识，以后直接搜手机号）。
6. **订单 → 开新单** —— 选客户、勾服务，价格自动算出来。

> 价格表页面的结构是 **游戏（一张价格表）→ 大类 → 服务项**。
> 服务项表单里的「游戏」和「大类」两个下拉是联动的：
> 换了游戏，大类列表只留这个游戏的和通用的；选了一个属于某个游戏的大类，游戏会自动跟着切过去。
> 这样就不会出现「游戏选崩铁、大类却是原神的日常」这种自相矛盾的价格项。

### 五种计价方式

| 方式 | 用在什么上 | 例子 |
| --- | --- | --- |
| 固定价 | 一口价的服务 | 周本全清 25 元 |
| 按天 | 包月、日常托管 | 每日委托 5 元/天 × 30 天 |
| 按次 | 一次一次算 | 清体力 3 元/次 |
| 按数量 | 数量越大越便宜 | 深渊 1~5 层 30/层，6~12 层 25/层 |
| 套餐价 | 打包一堆内容 | 活动全包 120 元/套 |

## 三、七个模块分别管什么

### 游戏管理
游戏名、简称、图标、区服列表、排序、上架/归档、备注、**顶部提示**。

**顶部提示**是对外给客户看的一句话（可以多行，一行一件事），和「备注」分开：

- 备注是你自己记账用的，**不会出现在导出里**；
- 顶部提示会出现在**导出图片 / Word 文档的最上方**（抬头下面、第一个大类上面），
  所以写之前想一下「这句话客户看到会不会有问题」。

导出多个游戏合并成一份时，顶部提示不会硬提到最上面（免得「鸣潮的提示」被当成整张表的说明），
而是各自跟在对应游戏的小标题下面。价格表页面里也会在游戏表头下面显示一遍。

界面上**不写「公告」这两个字**：提示条就是暖色底 + 左边一道朱砂竖线，自己就说明白了。
大类也有同款，见下面「两级提示」。

**删除是归档，不是真删。** 老订单里冻着游戏名，真删了档案就断了。
真要彻底删除，列表里也有那个按钮，但会先告诉你有多少订单和凭证挂着它。

### 服务与价格管理

价格表页面按 **游戏（一张价格表）→ 大类 → 服务项** 三层展开。
整页是按「一张价目表」来排的，不是按「一堆列表项」来排 —— 三级靠**字体、栏线和留白**区分：

```
鸣潮  官服                                  9 个大类 · 73 个服务项   [+ 新建大类]
═══════════════════════════════════════════════════════════════════════════
▌地图全收集 1230（星声 4.5W）                    ← 游戏的顶部提示（通栏）
▎日常  [每天做]  期间都会免费帮领取…  ──────────── ¥70 – ¥300  4 项
  ▌包月客户这个大类里所有套餐都能换着做。          ← 大类的提示（缩进、字小一号）
    单次下单按套餐算，不拆开卖。
    日体套餐                                      ¥70 /30天
    含 每日活跃+每日体力
▎探索 100%  按数量逐步定价  ──────────────────── ¥40 – ¥70  4 项
    瑝珑声匣 ············································· ¥50 /单
```

- **游戏表头**最大（大字 + 账簿双线），往下滚的时候**吸附在顶栏下面**，
  看一眼就知道自己在哪个游戏里；
- **大类**是中号字 + 前面一道朱砂刻度，名字后面一条栏线拉到底，
  右边坐着**价格区间**和项数 —— 所以收起状态也能扫一遍价位；
- **服务项**是账目行：名字在左、金额在右（等宽数字，一列对齐），中间点线相连；
- **管理按钮平时是收起来的**（鼠标进到那一行才出现），所以正文永远是一张能直接读的价目表。

#### 两级提示：游戏的排最上面，大类的排在这个大类里

游戏和大类都能写一条**对外提示**，都不用「公告」这两个字：

| | 写在哪 | 出现在哪 |
| --- | --- | --- |
| 顶部提示 | 游戏表单 | 整份价目表的**最上方**（抬头下面、第一个大类上面），通栏 |
| 大类提示 | 大类表单 | 这个**大类的名字下面**、服务项上面，缩进一格、字小一号 |

两处都跟「备注」分开：备注是你自己看的，**一个都不会进导出**。
导出图片和 Word 用的是同一份模型，所以两边看到的排版和内容完全一致。

#### 大类也能归档 / 彻底删除

大类那一行鼠标放上去，操作组里最后一个是垃圾桶：

- **归档大类**：先从价格表里收起来，服务项、价格、阶梯价全部原地不动；
- **彻底删除**：大类没了，底下的服务项**不会跟着消失**，只会变成「未分类」，
  还能重新归到别的大类里。已经开出去的老订单也不受影响 —— 价格冻在下单那一刻。

两个都会先告诉你这个大类底下挂着多少个服务项，再让你选。

- **服务项必须挂在大类里**，所以新建服务项的入口只在大类行上，没有「直接建服务项」这条路。
- 每个服务项能改价、改说明、上架下架。
- 按数量计价的可以配**阶梯价**。
- **增项**可以挂在某个服务项下，也可以建成全局通用（比如「全程录屏」）。
- 没绑游戏的大类会归到「通用」组；早期没归到大类的服务项会落在「未分类」里，照样能改。

#### 没填备注和套餐内容的服务项，会自动压成一行

规则很简单，**只看这一个服务项自己填了什么**，跟它属于哪个大类无关：

- **没填备注、没填套餐内容、没挂增项、没有阶梯价** → 排成一行：
  `北落野 ························· ¥25/单`
  鼠标放上去才露出拖动把手和「详情 / 改」两个按钮（触屏上一直显示）。
- **填了上面任何一样** → 照常铺开成多行，把内容都显示出来。

所以像「8 个地区价」那种，填了备注的那几行是铺开的，只有名字和价格的那行是紧凑的，
不会再在行里留一片空白。

#### 大类和层级

**大类默认全部收起。** 一进价格表先看到的是「这张价格表里有哪些大类、各值多少钱」，
想看哪个再点开哪个，不用在一屏拉不到底的长列表里翻。谁点开过就记住谁（刷新页面也还在）。
往收起的大类里加服务项时会自动帮你展开，方便看刚加的那条。

收起状态下也**不是**只能看到名字：每个大类右边都有价格区间（`¥70 – ¥300`）和项数，
扫一眼就知道这个大类值不值得点开。工具栏上还有**「全部展开 / 全部收起」**一次到底。

为了让「大类」和「服务项」一眼分得清：

- 游戏是**表头**：最大号字 + 账簿双线，吸顶；
- 大类是**分组标题**：中号字、前面一道朱砂刻度，后面一条栏线拉到底；
- 服务项是**账目行**：名字左、金额右，中间点线，缩进对齐到大类名字。

#### 拖动排序

**服务项**和**大类**都能拖，两套互不干扰：

- **按住一个服务项拖** —— 调整它在当前大类里的位置；
  **拖到另一个大类里**，就等于同时把这个服务项换了归属（游戏也跟着大类走）。
- **按住大类的标题拖** —— 调整大类顺序；
  **拖到另一个游戏那一组里**，就等于把这个大类换了游戏。

拖动时会有一条朱砂色的插入线告诉你落在哪。

顺序存在 `sort_order` 上，拖完会把整份顺序写回数据库，
所以刷新、换设备看到的位置都一样。

排序基于完整数据而不是当前显示的内容，**所以开着搜索或筛选拖也不会漏掉没显示的项**。

> 拖动用的是浏览器原生的拖放，鼠标和触控板都好使；纯触屏（手机）上拖不了，
> 那种情况就在电脑上排一次，手机上照着看。

改价格表**只影响之后开的单**。已经开出去的老单冻在下单那一刻的价格上。

### 导出价格表（图片 / Word 文档）

价格表右上角有个「**导出图片/文档**」。点开是这样一个面板：

```
导出范围    [每个游戏各出一份（推荐 · 分开的文件） ▾]
每个大类最多列几项 [6 项 ▾]   最多列几个大类 [8 个 ▾]
带说明文字  ☑     联系方式 [微信：xxx]   页脚说明 [价格随版本更新…]

预览  ┌──────────────┐
      │  渲染好的图片  │      ← 改任何选项，预览实时重画
      └──────────────┘

[关闭]                    [生成 Word 文档]  [生成图片]
```

**默认按游戏拆开，一个游戏一份文件，不会把几个游戏混在一起。** 发给客户时只发他那款游戏那份。
如果确实想要一张总表，把「导出范围」改成「全部游戏合并成一份」就行。

- **图片**：PNG，1080px 宽、2 倍图（实际 2160px），直接发微信、发朋友圈都清楚。
- **文档**：真正的 `.docx`，Word / WPS 都能打开和二次编辑。用的是「服务名 ······ 价格」的点线排版。
- **两者内容完全一致**——都从服务端同一个导出模型生成，不是两套逻辑各画一遍。

导出会自动裁掉多余内容，目的是**一张图一眼能看完**，不是把整张价格表塞进去：

| 裁掉什么 | 怎么处理 |
| --- | --- |
| 已下架的大类 / 服务项 | 不导出 |
| 空的大类 | 不导出 |
| 每个大类超出条数的服务项 | 折成「…… 这个大类还有 N 项」 |
| 超出数量的大类 | 折成「…… 还有 N 个大类没有列出」 |
| 过长的说明 | 截断成一行 |

导出是**跟着数据结构走**的，以后你新加什么都会自动带上，不用改代码：

- 新游戏 → 自动多出一份，并带上游戏小标题
- 新大类 / 新服务项 → 自动进对应分组
- **阶梯价** → 转成提示，例如「1-5层，最多到 ¥25/层」
- **增项** → 写进说明，例如「增项：加急 +20%、指定角色 +15元」
- **套餐内容** → 写进说明，例如「含 每日活跃+每日体力+周本」
- **没归到大类的服务项** → 不会静默丢掉，会落到「未分类」里一起导出
- 起订量 > 1 的 → 标出「起订 N 天」

### 客户管理
昵称、**头像**、手机号、微信、QQ、来源、标签、备注。点进客户档案能看到他的全部订单、收款流水、
登录凭证、报价单，以及累计金额和欠款。

**头像**选填，传一张图（1.5MB 以内）就行 —— 会显示在客户列表、客户档案页和订单列表的客户格上。
客户多了、重名了、或者名字很像的时候，一眼就能对上人。没传头像的用昵称首字当占位。

客户反复下单也不会乱：

- 客户档案里**先列在做的、已结束的收在后面**，各自封顶，多的折成「还有 N 张…」。
- 订单列表的客户格标出这是他的**第几单**，回头客一眼看得出。
- 订单页可以**按客户排**（同一个客户的单聚在一起），也可以点客户名直接进档案。

### 登录凭证保险箱
单独一张表，和联系方式分开。见下面第四节的规矩。

### 订单管理
下单那一刻会把**快照**冻住：客户名、游戏名、服务名、单价、数量、总价、
套餐内容、增项、下单时间。之后你改价格表，这张单一个数字都不会变。

#### 挑服务（下单台和报价单里都有）

```
挑服务                                        勾上就进单
[搜服务名…]  [全部游戏 ▾]  [全部大类 ▾]

▎日常                                          4 项      ← 分类标题吸顶，滚到哪都知道在哪
┌──────────────────────────────────────────────────┐
│ ☑ 活跃套餐                              ¥25/30天  │      ← 勾上的行整条提亮，左边一道朱砂
│   固定价                                          │
│   [2] 30天   [改价] 元                            │
├──────────────────────────────────────────────────┤
│ ☐ 日体套餐                              ¥50/30天  │      ← 没勾也看得到价格
│   固定价 · 周本可指定                              │
└──────────────────────────────────────────────────┘
[2] 已选                                    清空
```

- **可以按大类筛**。搜索、游戏、大类三个条件是「都要满足」，一起用。
- **大类列表跟着游戏走**：选了游戏就只列这个游戏的大类（加上通用的）；
  选过的大类要是不属于新游戏了，会自动退掉，免得筛出个空列表。
- 分类标题**吸顶**，滚到哪儿都知道自己在哪个大类里，右边标着这个大类有几项。
- **价格常驻显示**，不勾选也知道多少钱。
- 底部固定一条「已选 N 项」，旁边有「清空」。
- **筛掉不影响已勾的**：勾好、填好数量之后再换筛选条件，勾选和数量都还在，
  合计也照常算着它们。

#### 今日已完成（日体、包天这种天天要做的单）

日体、包天这类单**每天都要做**，做完就整单标「已完成」是不对的 —— 明天还得接着做。
所以订单详情页上有一个**「今日已完成」**：

- 点一下，这张单这个「今天」就**从「在做」列表里挪走**（看板的「进行中调度」也一起挪走），
  但状态还是「进行中」，钱和进度都没变。
- **过了凌晨 4 点它自己回到「在做」列表**（是 **4 点，不是 0 点**）——
  干到后半夜的人，凌晨 1 点做完的日体应该还算当天。不用做任何操作，也没有定时任务：
  标记时存的是**那个工作日的日期**，日期对不上就自动失效。
- 标错了、想今天就接着做 → 详情页按钮变成**「撤销今日完成」**，点一下回来。
- 想找这个「今天」标过哪些 → 订单页有个**「今日已完成」**筛选档。
- 已经真正「已完成」或「已取消」的单不给标（会提示）。

同一页上还有一个**「标记完成」**，那是**整张单结束**（永不再出现在「在做」里）。
状态机允许才会出现这个按钮 —— 还没确认 / 还没付款的单，得先走完前面的状态。

##### 哪些算「每天都要做」

**标在大类上**，不在单个服务项上：

- 名字里有**日常 / 日体 / 包天 / 每日 / 托管**的大类，建的时候**自动勾上**，
  以后新加的大类也认得出，不用手动设。
- 也可以在**大类表单**里手动勾 / 取消，价格表的大类标题上会显示「每天做」标记。

所以**以后往「日常」大类里加新的服务项，自动就算每天做** ——
哪怕那个大类和服务项是你明天才建的。

如果某个服务项要跟大类不一样（比如日常大类里的一次性附加项），
在**服务项表单**的「每天都做」里选「是 / 否」单独覆盖；默认是**跟随大类**。

##### 一张单里混着日常和一次性的活怎么办

比如「30天日体 + 两个活动」。两个办法，看你想要哪种：

**① 拆单**（订单详情右上角「拆单」）—— 把一次性的活挪到一张新单上，
两边**各自收款、各自结单**，互不牵扯：

```
DH260921-001  30天日体 + 两个活动     ¥130
        ↓ 拆单（勾上那两个活动）
DH260921-001  30天日体                ¥50     ← 天天标「今日已完成」
DH260922-002  30天日体（拆出）        ¥80     ← 自己走完成 / 收款
```

钱怎么分，规则是**说清楚**的：

- 每个服务项自己的金额（含它的增项）**跟着它走**；
- **折扣 / 手续费 / 成本留在原单**，新单从 0 开始（拆完可以各自再改）；
- **收款**在弹窗里选：
  - **按金额比例分到两张单**（默认）—— 已经收过的钱按两张单的新金额拆开，
    两边**各自结清**，加起来正好等于原来收的那笔（零头留在原单）；
  - **全部留在原单** —— 原单会变「多收」，拆的时候会提醒你多收了多少钱。
- **进度时间线**在弹窗里选：**留在原单**（默认）或**跟到新单**。
  进度是一段自由文字，没跟具体服务项挂钩，所以只能整批走或整批留。
- 客户、游戏、下单日期、交付日期、状态都照抄过去；标题会标「（拆出）」、备注写「拆自 DH…」。
- 原单必须**至少留一个**服务项，不能全拆走（整张都要挪的话，直接改那一张就行）。
- 拆出来的那笔收款也会标「拆自 DH…」，收款流水里能看出它是怎么来的。

> 收款和进度这两个选项只在**这张单已经记过收款 / 进度**时才出现，没记过就不问。

**② 不拆，直接标「今日已完成」** —— 点的时候会**先提醒你**，
把这张单里除了日常之外的活列出来（`若梦仍有回声、群声共振模拟域`），
让你确认这些也做完了。全是日常的单不会弹这个提醒，一步就标上。

订单详情的「服务明细」里，每天做的那条会带一个**「每天做」**标签，一眼看得出哪部分是日体。

#### 客户手机号

订单列表的客户格里直接显示**手机号**，要联系客户不用点进档案。客户头像、手机号、
「第 N 单」都在同一格，客户多了也能一眼对上人。

状态流转：

```
待确认 → 待付款 → 进行中 → 待验收 → 已完成
   ↘        ↘        ↘        ↘      ↓
              取消 / 售后 ←──────────┘
```

未按顺序跳转会被拦下来。**收款收满会自动从「待付款」推进到「进行中」**，省得再点一次。
已经记过收款的订单不允许直接删除（会让账对不上），要删得再加 `force`。

### 进度记录
每张单下面一条时间线：日期、完成内容、资源前后对比、截图/录屏链接、备注。
改了状态也会自动补一条进去。客户问「做到哪了」直接把那条发给他。

**「分享进度」按钮**（在进度时间线右上角）会把整条时间线整理成一份汇报，两种形式：

- **图片** —— 一张竖图，暖纸底 + 朱砂栏线，和价格表那张图同一套视觉，直接发微信。
  带单号、游戏、状态、已收 / 还差、每条进度的日期和资源变化（`160 → 40`）、备注。
- **文字** —— 同样内容的纯文本，点「复制文字」就能粘到微信里，想改两句就改。

截图原图塞不进这张图里，图上只会写「附 N 张截图」，图还是自己另发。

看板还会把**两天没记进度**的在做单挑出来提醒你。

**收款类型**有四种：**定金 / 全款 / 尾款 / 退款**。
第一次收款默认选「全款」（一次付清最常见），已经收过一部分再记就默认「尾款」。

### 财务
按时间段看：订单额、总收款、退款、净收、应收余额、平台手续费、成本、利润。
还有每日开单柱状图、按支付方式分组、按游戏分组、未结清清单、收款流水。

口径：订单额按**下单日**归集，收款按**到账日**归集，两者不必同月。
利润 = 订单额 − 平台手续费 − 成本，不含你自己的人工。

### 报价单
勾服务 → 价格自动算 → 实时生成一张报价单，可以**一键复制成文字发微信**，
也可以存下来。客户点头后，报价单**可以直接转成订单**。

## 四、保险箱的规矩

这是整个后台最敏感的地方，规矩是硬的：

- **优先扫码登录。** 能不存密码就不存密码——登录方式选「扫码登录」时，
  这条凭证可以一个密码字段都不填。
- **密码绝不存明文。** 账号、密码、密保、备注整块用 **AES-256-GCM** 加密后写进数据库。
- **密钥不存在任何文件里。** 它由你的「保险箱密码」用 scrypt（N=32768）推导出来，
  只活在服务器内存中。服务器一重启、你手动落锁、或者闲置 20 分钟，密钥就没了。
- **查看和复制要过第二道门。** 保险箱没解锁时，列表里只显示脱敏提示（`wa*****@qq.com`），
  内容是一张「封」条。要看明文得先输独立的保险箱密码。
- **谁、什么时候、看了哪条，全部留痕。** 「取用记录」里连解锁失败都记。
- **不存短信验证码、不存临时密码。** 那些一次性用完就该消失。
- **改保险箱密码会重新加密所有凭证。** 改之前建议先导出一份备份。

> ⚠️ **忘了保险箱密码就真的解不开**，没有后门、没有找回。请记在密码管理器里。

### 关于局域网访问的安全边界

用手机通过局域网访问时走的是普通 HTTP，**同一个 WiFi 下的其他人理论上能抓包看到你输入的密码**。
所以：

- 只在自家或信得过的 WiFi 下用手机访问；
- 在陌生网络里就用 `start-local.cmd` 只开本机；
- 后台对登录和保险箱解锁都做了失败限速（10 分钟内错 8 次就锁一段时间）。

## 五、备份与搬家

**数据全在 `data/` 目录里。** 把整个文件夹拷走就是完整备份。

也可以走「设置 → 导出一份备份」，会下载一个 JSON 文件（含全部业务数据）。
凭证在文件里仍然是**密文**，换台电脑要用同一个保险箱密码才能解开。
「从备份恢复」会用备份内容**覆盖**现在的全部数据，所以操作前会要你确认。

> SQLite 的 `data/console.db` 是主库，同目录下的 `-wal` / `-shm` 是它的运行时文件，
> 手动拷贝时三个一起拷最稳妥；用「导出备份」则没有这个顾虑。

## 六、几个运维小工具

```bash
node scripts/check.mjs            # 语法自检：把所有 .mjs / .js 过一遍
node scripts/inspect.mjs          # 只读查看库里有什么（游戏/大类/服务项/订单…），不改任何东西
node scripts/reset-password.mjs   # 忘了登录密码时用：清掉密码，下次启动回到初始化引导
node scripts/reset-password.mjs 我的新密码    # 或者直接设一个新密码（≥6 位）
node scripts/shot.mjs --help      # 无头浏览器截图（调界面时用，见下）
```

`inspect.mjs` 和 `reset-password.mjs` 都支持 `--data <目录>` 指向别的数据目录，
比如 `node scripts/inspect.mjs data/console.db`。

这两个脚本都**只动登录密码那两行设置**，游戏、价格表、客户、订单、凭证一概不碰。
保险箱密码是另一套，不受影响。

### 调界面时怎么截图

零依赖，用的是系统里现成的 Edge + Node 自带的 WebSocket（不需要装 puppeteer）：

```bash
node scripts/shot.mjs --url http://127.0.0.1:8802 --password 临时密码 \
     --route /price --out shots/price.png --width 1280 --height 900
```

它自己会登录、等页面渲染好、再截图，常用参数：

| 参数 | 作用 |
| --- | --- |
| `--route /price` | 登录后停在哪个页面 |
| `--full` | 截整页（默认只截一屏） |
| `--clip x,y,w,h` | 只截某一块，配合 `--scale 2` 看细节 |
| `--scale 0.5` | 输出缩放，缩小省事、放大看字 |
| `--wait ".pricelist"` | 等这个选择器出现再截 |
| `--scroll 1500` | 先滚到某处（验吸顶这种效果） |
| `--theme dark` | 切深色帐面 |
| `--eval-file x.js` | 截图前在页面里跑一段 JS（展开大类、点开抽屉…） |

**别用 `--eval` 传复杂 JS**：PowerShell 会把带分号/花括号的参数截断，
脚本一律写文件用 `--eval-file`。另外**不要**用 `--virtual-time-budget`，
这个 Edge 版本下虚拟时间会在请求落地前烧完，截出来永远是空壳。

## 七、常见问题

**双击 `start.cmd` 后窗口里刷出一堆 `'xxx' 不是内部或外部命令`？**
那是旧版启动脚本的编码问题，已经修好了——现在的 `start.cmd` 是**纯 ASCII** 的。
如果你手里还是会报错的那版，重新拿一份就行。

> 顺带说明启动脚本里为什么一个中文都没有：Windows 的 `cmd.exe` 按**系统代码页**读取 `.cmd` 文件，
> 文件里的 UTF-8 中文会被解错，错出来的字节还会把后面的行一起撕碎，
> 于是每个残片都被当成命令去执行。带 BOM 也一样救不了（实测过）。
> 所以中文提示全部交给 Node 打印——那部分是正常的 UTF-8 输出，显示完全没问题。

**窗口一闪就没了 / 提示需要 Node.js？**
说明这台电脑上没找到 Node.js。去 <https://nodejs.org> 下载 LTS 版本装上。
如果刚装完还是提示找不到，**关掉窗口重新开一个新的**——PATH 的改动只对新开的窗口生效。

**点「生成图片」没反应 / 下载文件夹里没东西？**
浏览器可能把「连续下载多个文件」拦掉了。导出范围改成「全部游戏合并成一份」就只下一个文件；
或者允许这个网站「下载多个文件」再试。图片也可以用 Chrome / Edge / Safari 打开后台来生成。

**生成 Word 文档打不开？**
它是标准的 `.docx`，Word 和 WPS 都能开。如果被手机当成未知文件，先存下来再用 WPS 打开。

**提示端口被占用？**
换一个端口：`start.cmd --port 8888`。

**手机打不开那个局域网网址？**
确认手机和电脑连的是同一个 WiFi；Windows 防火墙第一次会弹窗，要选「允许访问」；
公司/学校网络常常禁止设备之间互访，那种网络下手机连不上是正常的。

**忘了登录密码？**
关掉启动窗口，然后：

```bash
node scripts/reset-password.mjs            # 清掉密码，下次启动回到初始化引导
node scripts/reset-password.mjs 新密码      # 或者直接设一个新密码
```

只会动登录密码，**游戏、价格表、客户、订单、订单凭证一概不碰**。
保险箱密码是另一套，不受影响（所以更要记住保险箱密码——那个没有后门）。

**价格表里为什么不能直接建服务项？**
因为结构是「游戏（一张价格表）→ 大类 → 服务项」。先在大类行上点「加服务项」，
或者先「新建大类」。没绑游戏的大类会归到「通用」组里。

**换了台电脑，凭证打不开？**
备份文件里的凭证是密文，必须用**同一套保险箱密码**才能解开。
换了密码就不行了。

**想只在自己电脑上用？** 用 `start-local.cmd` / `./start.sh --local`。

## 八、技术上的事

- **零依赖**：`node:http` + `node:sqlite` + `node:crypto`，不需要 `npm install`。
- 前端是原生 ES 模块 + 原生 CSS，没有构建步骤，改完刷新页面就生效。
- 密码用 scrypt 哈希；会话是 HttpOnly + SameSite=Lax 的 Cookie，有效期 14 天。
- 数据库开了 WAL 和外键约束；迁移按 `PRAGMA user_version` 顺序前进，只增不改。
- 附 `PRODUCT.md` 和 `DESIGN.md`：前者是产品定义，后者是视觉与交互的规则书。

```
server.mjs            服务入口：路由分发、静态文件、启动信息
src/
  config.mjs          端口、路径、状态机、计价方式等常量
  db.mjs              SQLite 连接、表结构迁移、单号生成
  http.mjs            路由表、JSON、Cookie、静态文件、图片落盘
  auth.mjs            登录密码、会话、失败限速
  vault.mjs           保险箱：密钥推导、加解密、审计、改密重加密
  pricing.mjs         计价引擎（报价单和订单共用同一套）
  routes/             各模块接口
public/               前端（原生 JS + CSS）
data/                 运行时生成：console.db + uploads/
```
