## 现象

点「识别画面」后报：`上一条「识别画面」还没结束，这次没有切窗口。等它结束再试。`
但并没有另一条流程在跑。

## 根因

- 服务端 `/api/ocr/screen/focus` 要求请求体带当前流程的 `flow`（src/routes/system.mjs）；
- 前端唯一调用点 client/forms/resource-field.jsx:333 只传了 `game`；
- `/begin` 刚用 `flowId` 建了租约，因此 `active.id !== ''` 恒成立 → 每次必 409；
- 引入点 commit 23dae4a（切窗口必须带租约）：同批给 /key、/screen、/return 都补了 flow，漏了 /focus；
- 两种不同原因（请求里没带 flow / 别人占着）共用同一句文案，所以现象看起来像"我没点它却在跑"。

## 步骤

0. 基线 `npm run test`。
1. resource-field.jsx:333 补 `flow: flowId`。
2. /focus 错误三分：`screen_flow_gone`(409) / `screen_flow_missing`(400, 新增) / `screen_busy`(409)。
3. /api/ocr/screen 同样三分。

7. `npm run test` 全绿；第 6 条做一次"故意红"验证后恢复。
